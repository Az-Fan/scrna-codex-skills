# Method selection

- Use PROGENy for footprint-based signaling activity.
- Use Hallmark or a declared gene set for interpretable curated signatures.
- Use scMetabolism only when a metabolism-focused question justifies its broader gene-set machinery.
- Use cNMF to discover recurring expression programs; test multiple ranks and inspect stability and redundancy.
- Aggregate or model scores at the biological-sample level for condition inference.
