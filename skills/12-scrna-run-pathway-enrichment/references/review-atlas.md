# Database atlas contract

Config: enrichment_table, status_table, mapping_table, differential_table, output_dir (fresh), population, comparison_id, title, positive_label, negative_label, databases, fdr_threshold (0.05), top_per_direction (15), terms_per_page (1–30, default 30), max_jaccard (0.6), gene_examples (4). Run with existing R environment providing ggplot2/jsonlite and Ghostscript (`gs`) for merging variable-height pages. See config.review.example.json for portable configuration.

Inputs must be complete result tables for one declared contrast/population, not significant-only subsets. Preserve scientific columns. Display ranking is FDR ascending then stable pathway ID; greedily suppress leading-edge (GSEA) or hit-set (ORA) Jaccard > threshold within each database and direction, then retain Top N representatives. No cross-database semantic merging. Numerical FDR is kept visible, without requiring a separate significance legend.

Headers report result rows returned by enrichment (Up/Down split), finite-FDR row count, significant count before suppression (Up/Down split), requested Top N and its post-suppression meaning, total selected counts, current/total pages, and page displayed counts split by direction. ORA Up/Down are separate tests, so their totals count direction-specific results rather than unique pathway IDs. GSEA directions come from NES. Returned row counts reflect eligibility and implementation output; they are not all gene sets present in the database.

GSEA displays signed NES and a |NES| bar capped at 3, with an explicit caption; Core/set is leading-edge count / tested set size. ORA displays original FoldEnrichment and GeneRatio (hits / database-annotated input), with bar scaling shared across pages of that database. Up/Down input genes do not prove pathway activation/inhibition. Four directional gene examples are descriptive and need not individually pass a DE threshold. Mapping follows the source enrichment IDs, retaining original symbols and choosing one descriptive gene example per Entrez ID by largest absolute DE effect; this display choice does not reconstruct or change the original GSEA ranks.

Two PDF books retain all requested databases, including empty/zero significant/failure pages. Actual row count sets page height, never stretch sparse results onto a standard empty sheet. Large groups paginate without shrinking typography. Primary tables: enrichment_display_summary.tsv, page_summary.tsv, displayed_terms.tsv, selection_audit.tsv. Source and renderer hashes go under _provenance. Inspect one dense GSEA page, one ORA page, and one sparse page before delivery.

All modes select one population/comparison. Supply task_id and/or source_table (matching the result column input_table) when combined tables contain multiple source tasks. Unresolved task ambiguity fails. Source IDs are read as strings, preserving leading zeros; scientific columns are validated numerically. Source tables and config must lie outside a fresh output_dir. Tables are never rewritten.

This book mode supports PDF only; an explicit PNG request fails instead of silently exporting a second format. Compact dot/matrix mode supports either PDF or PNG.
