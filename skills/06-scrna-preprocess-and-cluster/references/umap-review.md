# Existing UMAP review

Copy [config.review-umap.example.json](config.review-umap.example.json) and run `Rscript <installed-skill>/scripts/review_umap.R <config.json>` with the existing registered Seurat environment. This standalone branch reads the object without normalization, clustering, embedding calculation or object export. Use a fresh output directory. It does not require preprocessing workflow selection or a new resolution decision.

Configure `input.object`, `metadata.sample`, `metadata.cluster`, and `metadata.reduction`. The embedding must cover every input cell exactly once and contain finite coordinates. `review_umap.sample_order`, if supplied, must contain every sample exactly once. `review_umap.cluster_colors` is an optional named mapping covering all clusters; aliases that resolve to identical RGB colours are rejected. Otherwise numeric cluster IDs sort numerically and receive a reproducible categorical palette. Above 20 clusters, inspect distinguishability and retain labels; unique colours do not guarantee perceptual separation.

The labelled cluster UMAP exports `cluster_colors.tsv`. Sample panels show every cell in grey and the selected sample in blue, with identical coordinates and axis limits and cell counts in titles. Four panels fit each page. Point sizes adapt to input cell count; override `review_umap.point_size` with a positive number when needed. Default outputs are `cluster_umap.pdf` and one multi-page `sample_highlights.pdf`; choosing PNG produces only PNG figures, one file per sample page. Integrated fixed/finalized clustering uses a `<scenario>_review_` prefix and retains existing diagnostics.

`sample_cluster_counts.tsv` includes all sample×cluster combinations, including zeros. `sample_fraction` uses all cells of that sample as denominator; `cluster_fraction` uses all cells of that cluster. Both respective fraction sums must equal one, and total counts must equal input cell count. Methods, hashes and sessions remain under `_provenance/`; standalone `RESULTS.md` links the figures and tables. Inspect the cluster figure and every sample page before delivery.

UMAP overlap alone cannot establish absence of batch effects. Representation differences may reflect cell composition, biological conditions or QC. Do not infer technical batches from sample IDs or use this descriptive plot as a formal abundance test.
